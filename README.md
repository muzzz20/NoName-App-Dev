# Strayfriends

> A mobile + web application addressing the well-being of stray cats at Universiti Teknologi Malaysia (UTM).
> Course: SCSJ3104 Application Development · Group: NoName · Jira: `NAD`

## Core Modules

1. **Reporting** — submit cat sightings with photo, location, condition
2. **Fundraising** — transparent donation tracking with allocations
3. **Volunteer Coordination** — activities and sign-ups

## Stack

- **Frontend:** Flutter 3.41+ (Android / iOS / Web)
- **Backend:** Firebase (Auth · Firestore · Storage · Cloud Messaging)
- **PM:** Jira (project `NAD`) + GitHub (linked commits)

## Prerequisites

| Tool | Min Version | Install |
|---|---|---|
| Flutter SDK | 3.41 | https://docs.flutter.dev/get-started/install |
| Dart SDK | 3.11 | bundled with Flutter |
| Firebase CLI | 14+ | `npm install -g firebase-tools` |
| FlutterFire CLI | latest | `dart pub global activate flutterfire_cli` |
| Android Studio / Xcode | latest | platform SDKs for build |

## Setup

```bash
# 1. Clone
git clone <repo-url>
cd strayfriends

# 2. Install dependencies
flutter pub get

# 3. Firebase auth (one-time)
firebase login
flutterfire configure   # select existing project: strayfriends-utm

# 4. Run
flutter run -d chrome       # web
flutter run -d <device-id>  # android/ios — list devices: flutter devices
```
